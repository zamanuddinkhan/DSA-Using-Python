# DSA Using Python

A structured collection of **Data Structures and Algorithms concepts, Python implementations, coding problems, and interview preparation**.

## 📚 About

This repository contains my **DSA learning journey using Python**.

It focuses on understanding data structures, implementing algorithms from scratch, analyzing time and space complexity, and solving coding problems commonly asked in **technical interviews, coding rounds, and placement tests**.

## 🎯 Learning Objectives

* Build strong DSA fundamentals using Python
* Improve problem-solving and logical thinking
* Understand time and space complexity
* Implement important data structures
* Learn and implement common algorithms
* Solve coding problems efficiently
* Learn different problem-solving patterns
* Prepare for coding interviews and placements

| Linear Search              | O(n)                    |
| Binary Search              | O(log n)                |
| Hash Table Search          | O(1)                    |
| Stack Push                 | O(1)                    |
| Stack Pop                  | O(1)                    |
| Queue Enqueue              | O(1)                    |
| Queue Dequeue              | O(1)                    |
| Bubble Sort                | O(n²)                   |
| Selection Sort             | O(n²)                   |
| Insertion Sort             | O(n²)                   |
| Merge Sort                 | O(n log n)              |
| Quick Sort                 | O(n log n)              |
| Heap Sort                  | O(n log n)              |
| BFS                        | O(V + E)                |
| DFS                        | O(V + E)                |
| Dijkstra's Algorithm       | O((V + E) log V)        |
